快速同步（剪贴板）

手机电脑互传：在一台设备点击「复制全部数据」，通过微信/QQ发送到另一台设备，复制文本后点击「从剪贴板导入」即可。

GitHub 云同步 推荐

GitHub API 原生支持浏览器跨域，不会出现 Failed to fetch。数据以私密 Gist 保存在你的 GitHub 账号，免费且稳定。 点此生成 GitHub 访问令牌（勾选 gist 权限即可）。

令牌仅存在你当前浏览器的本地存储中，不会上传到任何第三方服务器。上次 GitHub 同步：从未

数据管理

所有数据均存储在您浏览器的本地存储（localStorage）中，不会上传到任何服务器。清除浏览器数据或更换设备会导致数据丢失，建议定期导出备份。
